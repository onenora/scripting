# XBS Converter

香色闺阁书源 XBS 与 JSON 互转：书源库管理、JSON 预览与编辑、约束检查与一键修复、导出 XBS / JSON。

## 使用

1. 导入 .xbs / .json（可多选），或粘贴 JSON、从模板新建；也可从「文件」分享给本脚本。
2. 卡片「JSON」打开编辑器，「详情」管理文件内各个书源。
3. 点按「N 项提示」查看检查结果，标「可修复」的项可一键修复。
4. 「导出」选择 XBS 或 JSON；右上角「设置」可填写导出密码，写入 XBS 的 `password` 字段。

算法来自 [minis-skills · xiangse-sources](https://github.com/onenora/minis-skills/tree/main/xiangse-sources)，设计见 [design.md](design.md)。
