# Script Store

浏览并一键安装社区 Scripting 脚本：搜索、排序、本地收藏、作者作品页，以及发布自己的脚本。

## 使用

1. 首次打开加载商店列表并保存在本机，之后打开直接显示上次的列表，下拉刷新；搜索名称、描述或作者，横向「热门」展示安装最多的 10 个脚本。
2. 卡片「获取」直接打开 Scripting 的导入确认；点按卡片进入详情，右上角收藏、复制 / 分享 / 在 Safari 打开链接，点按作者名查看其全部作品。
3. 卡片右滑收藏或取消收藏，收藏的脚本显示在主页「收藏」分组。
4. 右上角「显示选项」切换「最近更新 / 安装最多 / 名称」排序，以及选择界面字体（系统已安装字体，可配合 [Fonts Installer](../fonts-installer/) 安装）。
5. 右上角 + 发布脚本，提交后公开可见。

数据来自第三方站点 [scripting.roayc.com](https://scripting.roayc.com)，非 Scripting 官方平台；脚本由各自作者提供，安装前请确认来源可信。架构与设计见 [design.md](design.md)。
